# CarX Тюнинг 2.0

Подсказчик настроек для **CarX Drift Racing Online**. Автор: Sparrow.

**[Скачать последнюю версию](../../releases/latest)** — файл `CarX_Tuning_2.0.zip`.

## Как запустить
1. Распакуй архив в любую папку.
2. Запусти `carx_tune_v2.exe`. Python ставить не нужно.
3. Если Windows напишет «Система Windows защитила ваш компьютер», нажми «Подробнее», потом «Выполнить в любом случае». Так бывает с любой программой без цифровой подписи.

## Что умеет
- Подбирает тюн под машину, массу, мощность и трассу.
- «Что не так?»: одна правка за раз по симптому и кнопка «Отменить шаг».
- Читает тюны мода Kino и сохраняет новый тюн в Kino отдельным файлом.
- Коробка передач, сравнение с Kino, библиотека тюнов, код тюна для друзей.

## Важно
- Существующие файлы игры и Kino программа не меняет: новый тюн сохраняется отдельным файлом.
- Тип дифференциала программа не записывает, его выбирают в игре.
- Подсказки — отправная точка. Проверяй тюн в заездах и подстраивай под себя.
