# Библия (WebXR) — Библия как космос

Библия в виде звёздного неба для VR-шлема. Каждая звезда — стих, каждое скопление звёзд — книга.
Работает в браузере шлема (Meta Quest Browser, Pico, Vision Pro Safari с WebXR), а также на компьютере и телефоне.
Два языка интерфейса и текста: русский и румынский (кнопки RU / RO). Текст — ваши файлы EPUB. Стихи можно слушать вслух.

## Как устроено небо

1. **Галактика книг.** Книги идут по спирали вокруг вас в библейском порядке: Бытие спереди внизу,
   дальше по часовой стрелке и вверх до Откровения. Цвет скопления — жанр книги
   (Закон, исторические, учительные, пророческие, Евангелия, Деяния, послания, Откровение).
   Внутри скопления стихи лежат
   по спирали от центра наружу, главы чередуются оттенком, первая звезда каждой главы крупнее.
2. **Книга.** Скопления-главы окружают вас рядами, как страницы: слева направо, сверху вниз.
3. **Глава.** Стихи стоят вокруг вас колонками на расстоянии вытянутой руки, как страницы книги: стихи одного
   абзаца сливаются в общий блок, поэзия (псалмы, пророки) идёт строками с отступами, глава открывается крупной
   золотой цифрой, сверху — заголовок с орнаментом, звёзды стихов на полях соединены тонкой нитью.
   Абзацы и строки берутся из разметки EPUB; если файл открыт до этой версии, откройте его заново.
   Длинные главы делятся на страницы.

## Управление

| | VR | Компьютер / телефон |
|---|---|---|
| Прочитать стих | Навести луч на звезду | Навести мышь |
| Открыть книгу или главу | Курок (или щипок рукой) | Щелчок / касание |
| Назад | Кнопка B или Y, либо панель внизу | Esc или «хлебные крошки» вверху |
| Повернуться | Стик влево-вправо | Перетаскивание, стрелки |
| Соседняя глава | Панель внизу | Кнопки внизу, клавиши `[` и `]` |
| Перейти к месту | — | Поиск: «Ин 3:16», «Бытие 1», «1 Кор 13», «Ioan 3:16» |
| Слушать | Курок по стиху или «▶ Слушать» на панели | Щелчок по стиху, кнопка «Слушать главу» или пробел |

## Небо

Вокруг галактики книг — глубокий космос (`sky.js`): Млечный Путь с пылевыми прожилками, цветные туманности,
яркие звёзды с лучами, далёкие спиральные галактики, три чёрные дыры с вращающимся аккреционным диском
(одна почти над головой, одна внизу позади), квазары с джетами, падающие звёзды, газовый гигант с кольцами
(внизу слева, освещён далёким солнцем) и кольцевая туманность.
Фон рисуется один раз при запуске в кубическую текстуру, поэтому в VR он почти не нагружает видеокарту.

Объём: вокруг медленно плывёт близкая космическая пыль. В VR она смещается при движении головы и даёт ощущение
пространства, на экране камера чуть покачивается. В главе пыль почти гаснет, чтобы не мешать чтению.
При системной настройке «уменьшить движение» покачивание и падающие звёзды отключаются.

## Переходы и управление

- При открытии книги или главы — «прыжок»: следы звёзд летят навстречу, стихи слетаются на свои места,
  скопления глав разлетаются из центра. При «уменьшить движение» остаётся простое затемнение.
- «⌂ В начало» (или щелчок по названию) возвращает к галактике книг и сбрасывает вид; в VR — кнопка «⌂ Начало».
- «Подсказки: вкл/выкл» скрывает обучающие подсказки (выбор запоминается). У подсказки, легенды жанров,
  справки о книге и карточки стиха есть крестик.

## Связи между стихами и история книг

- **В галактике** при наведении на звезду от неё тянутся золотые дуги к связанным стихам в других книгах.
- **В главе** щелчок (в VR — курок) по стиху открывает карточку: текст, до 10 связанных стихов с переходом к ним,
  кнопка «Слушать отсюда» и справка о книге.
- **Справка о книге**: кто написал, где, когда, какое время описано и при каких обстоятельствах.
  Показывается при открытии книги и в карточке стиха.

Связи взяты из базы перекрёстных ссылок [OpenBible.info](https://www.openbible.info/labs/cross-references/)
(лицензия CC BY), для каждого стиха — до 10 ссылок с наибольшим числом голосов (`data/xref.json`,
собирается скриптом `tools/build_xref.py`). Ссылки записаны в обычной нумерации 66 книг. Если открыт перевод
с нумерацией по Септуагинте (как Синодальный), номера псалмов пересчитываются.

Справка о книгах (`data/books-info.json`) составлена по традиционной датировке, даты приблизительные.
Если загружен EPUB с jw.org, писатель, место, год и охваченное время берутся из таблицы книг самого издания,
а строка об обстоятельствах — из `books-info.json`.
Точную дату для отдельного стиха указать нельзя: известны даты книг, а для некоторых псалмов — обстоятельства из надписаний.

## Кто написал книгу и викторина

- **Биографии писателей и пророков** (`data/people.json`, 33 человека, русский и румынский): кто это был, когда жил,
  чем известен. Видны в справке о книге и в карточке стиха.
- **Рассказчик**: кнопка «▶ Рассказать» читает вслух справку о книге, биографию писателя и обстоятельства написания.
  В VR — кнопка «▶ Рассказ» на панели внизу.
- **Викторина «Угадай книгу»**: показывается случайный стих и четыре книги на выбор. После ответа правильная книга
  вспыхивает в галактике, а «Показать в космосе» переносит прямо к этому стиху. Есть счёт, чтение стиха вслух,
  в VR — объёмная панель с кнопками.

## Личное небо и удобство

Всё личное хранится только на этом устройстве (localStorage) и общее для всех переводов.

- **Касание на телефоне**: первое касание показывает стих и книгу, второе открывает (нет наведения мышью).
- **Обзор поворотом телефона** (Настройки): поворачиваете телефон и осматриваете небо, как в VR.
  Работает в APK и в браузере телефона; во встроенном окне claude.ai датчик недоступен.
- **«Продолжить: Ин 3»** — кнопка внизу галактики открывает последнюю главу.
- **Настройки** (меню «Ещё»): размер текста, скорость чтения, голос, гироскоп, порядок книг, подсказки, сброс прогресса.
- **Закладки**: «☆ В закладки» в карточке стиха; закладки горят в галактике золотыми звёздами, список — в меню.
- **Прогресс чтения**: глава считается прочитанной через 12 секунд в ней или когда дочитана вслух;
  прочитанные главы светятся ярче, в книге отмечены «✓», счётчик — в легенде.
- **Созвездия тем**: «Любовь», «Вера», «Надежда», «Воскресение», «Молитва», «Мир», «Прощение», «Мудрость»,
  «Царство Бога», «Творение» — стихи темы соединяются линиями через всю галактику.
- **Стих дня**: один раз в день при запуске звезда дня вспыхивает, стих можно послушать или перейти к нему.
- **Поиск по словам**: если в поиске не место («Ин 3:16»), а слова («возлюбил Бог мир»), ищется по всему тексту,
  найденные стихи подсвечиваются голубым в галактике.
- **Порядок «по времени написания»**: книги выстраиваются по годам от Бытия (1513 г. до н. э.) до Откровения.
- **VR**: левый стик — полёт по галактике в сторону взгляда, правый — поворот; руки без контроллеров — щипок
  пальцами вместо курка (Quest, отслеживание рук).

## Изучение

- **Заметки**: в карточке стиха поле «Моя заметка»; стихи с заметками горят на небе мятным цветом,
  на карточке — значок ✎, список — «Ещё → Заметки». Хранятся только на устройстве.
- **Карта мест и маршрутов** («Ещё → Карта»): 52 библейских места на карте Восточного Средиземноморья
  (контуры суши, озёр и рек — Natural Earth, общественное достояние, `data/map.json`). Нажмите на место — список
  стихов о нём; в карточке стиха — кнопки мест, упомянутых в стихе. Маршруты: путь Авраама, Исход,
  три путешествия Павла и плавание в Рим. В VR карта открывается объёмной панелью.
  **24 путешествия** по эпохам: Авраам, Иаков в Харран, Иосиф, Иаков в Египет, Исход, Иисус Навин, Руфь и Ноеминь,
  Давид в бегах, Илия, Иона, Вавилонский плен, возвращение, Неемия, рождение Иисуса и бегство в Египет, Иисус в Галилее,
  через Самарию, последний путь в Иерусалим, Филипп, Савл в Дамаск, Пётр, три путешествия Павла и путь в Рим.
  У каждого — описание, остановки (нажмите — стихи о месте) и «Читать». «★ Все путешествия» показывает все пути сразу,
  каждый своим цветом, с легендой по эпохам. Пути показаны приблизительно.
  Карту можно увеличивать: двумя пальцами, колёсиком мыши, кнопками «+»/«−» или двойным касанием; пальцем — двигать,
  «⤢» — весь регион. При увеличении включается подробная береговая линия (Natural Earth 1:10 млн), появляются названия
  морей и рек (Галилейское и Солёное море, Иордан, Нил, Евфрат…) и масштабная линейка. Место, открытое из карточки
  стиха, сразу показывается крупно. В VR у карты есть кнопки «+» и «−».
- **Планы чтения** («Ещё → План чтения»): Библия за год, Новый Завет за 3 месяца, Евангелия, Псалмы, Притчи
  за месяц. Каждый день — главы на сегодня, прогресс, кнопка «План на сегодня» в галактике.
- **Лента событий** («Ещё → События»): от Сотворения до Откровения, с переходом к стихам.
  Годы по традиционной хронологии, приблизительные.
- **Поделиться стихом**: картинка 1080×1350 со стихом на звёздном фоне. В APK — системное окно «Поделиться»,
  в браузере — окно «Поделиться» телефона или картинка, которую можно сохранить.
- **Викторина** с уровнями: «Книга», «Продолжи стих», «Глава и стих»; счёт, серия и рекорд по каждому уровню.

## Режим чтения и «Уроки для жизни»

- **Режим чтения** («📖 Текст» внизу; на телефоне включён сразу): глава крупным чётким шрифтом, как страница книги —
  абзацы по изданию, стихи поэзии строками, номера стихов. Сверху «Суть главы», ниже люди в главе, факт и связи.
  A−/A+ меняют размер шрифта, касание стиха открывает его карточку, звучащий стих подсвечивается и сам
  прокручивается. «✦ Космос» возвращает главу в пространство; выбор запоминается.
- **Книга в режиме чтения** — страница-оглавление: крупное название, все главы большими кнопками (прочитанные
  отмечены золотой чертой), для книг с краткими содержаниями — список глав с первой фразой содержания; ниже
  справка о книге, кто её написал и «▶ Рассказать». Названия книг в галактике тоже стали крупнее и ярче.
- На телефоне кнопки внизу умещаются в одну строку, а верхняя панель стала компактнее (значки ⌂ ✦ ?).
  В главе разрешение не опускается ниже 1,5, поэтому текст в космосе тоже не размывается.
- **Уроки для жизни** («Ещё → Уроки для жизни»): Библия как инструкция для человека — девять ступеней:
  замысел, поломка, диагноз, ремонт, правила, примеры, обслуживание, неисправности и цель. У каждой —
  объяснение (RU/RO), 7–10 стихов из вашей Библии и созвездие на небе. «▶ Слушать урок» читает объяснение и стихи,
  «▶ Слушать все уроки» — все ступени подряд (тоже в фоне).

## Аудио-Библия (записи чтецов)

«Ещё → Аудио-Библия → Выбрать папку с записями»: программа берёт все MP3 вида `nwt_01_Ge_U_01.mp3`
(номер книги, язык U — русский / M — румынский, номер главы) — например, записи «Перевода нового мира» с jw.org —
и сохраняет их **только на этом устройстве** (отдельная база IndexedDB `bible-audio`); в программу записи не встраиваются.
Показывает, сколько глав есть и каких не хватает. Если запись главы есть, «Слушать» включает живой голос чтеца;
где записи нет — читает голос устройства.
- **Подсветка стихов без меток.** В файлах нет отметок начала стихов, поэтому программа сама находит их при первом
  прослушивании главы: ищет паузы чтеца и выбирает те, при которых все стихи читаются примерно с одной скоростью
  (букв в секунду). На записях Бытия 1 и 2 разброс скорости между стихами — меньше 1–1,5 буквы в секунду.
  Найденное время запоминается, поэтому «Слушать отсюда» сразу начинает с нужного стиха.
- Главы подряд, чтение в фоне и при заблокированном экране (в APK — та же служба «Чтение вслух»), скорость — из настроек.
- В APK «Выбрать папку» открывает системный выбор папки и передаёт программе все MP3 из неё и вложенных папок.

## Пророчества

«Ещё → Пророчества» — 71 пророчество в пяти разделах: **о Мессии** (27), **народы и города** (11),
**Израиль и Иерусалим** (11), **последние дни** (9 признаков) и **обещания о будущем** (13). В каждой карточке —
что предсказано (стих из вашей Библии), исполнение (стихи или подтверждение историей), когда записано и когда
исполнилось, объяснение (RU/RO). «▶ Слушать» читает пророчество вслух, «▶ Слушать раздел» — весь раздел подряд
(и в фоне), «✦ На небе» рисует дугу от звезды пророчества к звезде исполнения. Файл: `data/prophecies.json`.

## Объяснения и связи

- **«О главе»** — панель слева при открытии главы: краткое содержание (пока Бытие и все четыре Евангелия,
  RU и RO), люди в главе (нажмите — биография и все упоминания), книги, с которыми глава связана сильнее всего
  (полоски; «Показать на небе» рисует созвездие связей главы), и «Знаете ли вы?» — факт о книге.
- **Карточка стиха** дополнительно показывает: людей в стихе, понятия с объяснением (59 слов: Иегова, Шеол,
  крещение, скиния…), меры и деньги в привычных единицах (локоть ≈ 44,5 см, денарий — дневная плата…),
  **сноски издания** из вашего EPUB, **параллельные места Евангелий** с кнопкой «Сравнить» (рассказы
  рядом в колонках) и **цитаты из Ветхого Завета** (102 места, голубые дуги на небе, «исполнение пророчества»).
- **Путешествие по связям**: «→ Дальше по связи» ведёт к следующему связанному стиху, путь запоминается
  («Ещё → Мой путь») и рисуется на небе розовой нитью.
- **Скорость**: «Настройки → Графика»: «Авто» (по умолчанию) следит за плавностью и, если кадры идут медленно,
  сначала выключает свечение, затем уменьшает разрешение, а при запасе скорости возвращает его; «Быстрая» —
  самый плавный вариант и бережёт батарею; «Красивая» — все эффекты. На телефонах свечение по умолчанию выключено.
- **Графика**: свечение ярких звёзд (bloom, выключается в настройках), форма скоплений по жанру книги
  (закон — ровные диски, история — спирали, поэзия — «цветы», пророки — кольца, письма — сферы),
  символы над группами книг и «живые» дуги связей с бегущими искрами.
- Файлы: `data/summaries.json`, `figures.json` (88 человек), `facts.json` (по 2 факта на книгу),
  `parallels.json` (58 событий), `otquotes.json`, `glossary.json`. Краткие содержания других книг можно добавлять
  в `summaries.json` в том же виде.

## Советник (искусственный интеллект)

Меню «☰ Ещё» → «🤖 Советник», или кнопка «Спросить советника» в карточке стиха. Это Claude (Anthropic). Ему заранее рассказано, что это за программа и что в ней есть. Имя по умолчанию — «Тарс», его можно поменять.

- **Глаза.** К каждому вопросу прикладываются снимок экрана программы и описание того, что открыто: книга, глава с текстом, карточка стиха, открытые окна. Окно советника на снимке скрыто. На компьютере снимается всё окно, на телефоне — экран приложения, в браузере — 3D-сцена. Кнопка «👁 Видит экран» выключает глаза.
- **Ссылки.** Ссылки вида «Ин 3:16» в ответах становятся кнопками и открывают стих.
- **Голос.** У советника свой голос, отдельно от голоса чтения: на компьютере это нейросетевой «Дмитрий» (или «Денис»). Голос выбирается в настройке советника (⚙), там же кнопка «Проверить».
- **Ключ.** Нужен свой ключ Anthropic API (console.anthropic.com → API Keys), оплата по использованию. Ключ хранится только на устройстве и отправляется только на api.anthropic.com.

Официальный SDK Anthropic лежит одним файлом в `vendor/anthropic-sdk.js`; пересобрать его можно скриптом `tools/build-ai-sdk.sh`.

## Атмосфера

- **Музыка космоса** («Ещё → Музыка»): спокойные аккорды и мерцающие ноты рождаются прямо в программе (Web Audio,
  без файлов). Пока звучит голос, музыка становится тише. Громкость — в настройках.
- **Режим «Тишина»** (кнопка «☾ Тишина» в главе, в VR — на панели): исчезают кнопки и пыль, фон темнеет,
  глава читается вслух, а дальше следующие главы подряд. Выход — кнопка в углу, Esc или B/Y на контроллере.

## Озвучка

- **Чтение в фоне.** В APK вся глава сразу ставится в очередь синтезатора Android, поэтому чтение продолжается,
  если свернуть программу или выключить экран. В шторке появляется уведомление «Чтение вслух» с кнопкой
  «Остановить» (на Android 13+ программа один раз спросит разрешение на уведомления). Когда вы возвращаетесь,
  на экране открывается звучащая глава и подсвечен стих.
- Так же в фоне звучит и «▶ Рассказать» о пророке или писателе книги.
- Если телефон всё равно останавливает чтение при блокировке (так делают некоторые Xiaomi, Huawei, Samsung),
  нажмите «Ещё → Настройки → Разрешить работу в фоне» — откроется системное окно, разрешите работу без ограничений
  батареи. Программа один раз подскажет это сама. Если система всё же закроет страницу программы в фоне,
  она создаётся заново, а голос продолжает читать.
- **Главы подряд** (настройка, включена по умолчанию): дочитав главу, голос переходит к следующей,
  а после последней главы книги — к следующей книге. Прочитанные главы отмечаются.
- **Голос получше.** Программа сама выбирает лучший голос: в APK — голос синтезатора Android с самым высоким
  качеством (сетевые голоса Google, если есть интернет), в браузере — нейронные голоса «Natural»
  (Microsoft Edge), затем Google; голоса-«роботы» (eSpeak и т. п.) в конце списка. В «Настройках» можно выбрать
  голос вручную, послушать пробу, изменить скорость и высоту, а в APK — «Установить голоса»
  (системная загрузка голосов, например румынского).
- Между стихами короткие паузы, сокращения читаются полностью («до н. э.» → «до нашей эры»), длинные стихи
  делятся на фразы, чтобы голос не обрывался.
- В браузере на телефоне на экране блокировки появляются кнопки «пауза», «следующая» и «предыдущая глава».

## Запуск

Нужен любой статический веб-сервер, просто открыть файл не получится из-за загрузки `data/bible.json`.

```bash
cd bible-cosmos-vr
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для шлема страницу нужно открыть по HTTPS. Самый простой путь — GitHub Pages:
Settings → Pages → Build and deployment → Source: «Deploy from a branch» → ветка `claude/greeting-540bqn`,
папка `/ (root)` → Save. Через минуту программа открывается в браузере шлема (Meta Quest Browser, Pico):
`https://se8rver78682ops.github.io/carx-tuning/bible-cosmos-vr/` → «Открыть файлы EPUB» → «Войти в VR».
Файл `.nojekyll` в корне отключает обработку Jekyll, чтобы файлы отдавались как есть.

APK на шлеме Quest работает только как плоское окно (WebView в Android не поддерживает WebXR),
поэтому для настоящего VR нужен браузер шлема.

## Текст Библии

Программа не содержит текстов Библии. При первом запуске она просит открыть ваши файлы, например
«Перевод нового мира» с jw.org на русском (`nwt_U.epub`) и румынском (`nwt_M.epub`); можно выбрать оба сразу.
Текст разбирается прямо на устройстве и хранится там же (IndexedDB), поэтому файлы открываются один раз,
а дальше всё работает без интернета. Язык определяется по тексту. Кнопка RU или RO для ещё не открытого языка
предлагает выбрать его файл. «Ещё → Открыть EPUB…» заменяет перевод.

Тексты с jw.org защищены авторским правом, поэтому в проект, на страницу и в APK они не включаются:
каждый открывает свой файл для личного чтения.

Подходят:

- **EPUB** с jw.org. Стихи берутся по якорям `chapterN_verseM`, надписания псалмов ставятся в скобках
  перед первым стихом, сноски пропускаются; писатель, место и годы — из таблицы книг издания.
- **RTF** с jw.org: zip-архив `nwt_*_U.rtf.zip` или отдельные файлы `nwt_NN_Книга_U.rtf`.
- **JSON** в формате ниже.

Формат JSON:

```json
{
  "t": "Название перевода",
  "b": [
    { "n": "Бытие", "s": "Быт", "c": [["Стих 1:1", "Стих 1:2"], ["Стих 2:1"]] }
  ]
}
```

## Приложение для Android (APK)

Папка `android/` — обёртка WebView: программа работает без интернета (three.js, связи и справки внутри APK;
текст Библии — ваши EPUB, их выбирают при первом запуске из файлов телефона), стихи читает встроенный синтезатор
речи Android (в WebView нет браузерной озвучки), кнопка «Назад» поднимается по уровням: глава → книга → галактика.

Собрать можно двумя способами:

- **GitHub Actions** (`.github/workflows/bible-cosmos-apk.yml`): после отправки изменений в GitHub workflow сам собирает
  `bible-cosmos.apk`. Он появится во вкладке Actions → запуск «Bible Cosmos APK» → Artifacts.
  Запустить вручную можно кнопкой «Run workflow».
- **На своём компьютере** с Android Studio или Android SDK:

  ```bash
  bash bible-cosmos-vr/android/prepare-assets.sh
  cd bible-cosmos-vr/android && gradle assembleDebug
  # APK: app/build/outputs/apk/debug/app-debug.apk
  ```

Это отладочная сборка: при установке Android попросит разрешить установку из неизвестных источников.
В APK нет VR-режима: Android WebView не поддерживает WebXR. Для шлема (Meta Quest) открывайте ссылку
в браузере шлема.

## Программа для компьютера (Windows, Linux, macOS)

Папка `desktop/` — та же программа в окне Electron. Сборку делает GitHub Actions
(`.github/workflows/bible-cosmos-desktop.yml`) при каждом изменении:
- **Windows**: `Bible-1.0.0-setup.exe` (установщик с ярлыком «Библия») и `Bible-1.0.0-portable.exe` (без установки);
- **Linux**: `Bible-1.0.0-linux-x86_64.AppImage`;
- **macOS**: `Bible-1.0.0-mac-arm64.dmg` и `…-x64.dmg` (без подписи: первый запуск — правой кнопкой → «Открыть»).

Скачать: GitHub → Actions → «Bible Cosmos desktop» → последний запуск → Artifacts.
Работает без интернета (three.js и JSZip внутри), F11 — во весь экран, Ctrl +/− — масштаб;
чтение вслух продолжается, когда окно свёрнуто. Тексты Библии — из ваших EPUB, хранятся только на компьютере.
Собрать самому: `cd desktop && npm install && npm run dist`.

**Голос на компьютере.** Программа Electron читает голосами системы (в Windows это, например, «Microsoft Irina»).
Самые естественные голоса Microsoft — «Svetlana (Natural)» и «Ioana (Natural)» — есть только в браузере Microsoft Edge:
откройте веб-версию (GitHub Pages) в Edge и установите её как приложение (меню «…» → «Приложения» → «Установить этот сайт
как приложение»); в «Настройках» программы выберите голос с пометкой «Natural».
Сборка для Windows и Linux включает нейросетевой голос **Piper** (работает без интернета): синтезатор с github.com/rhasspy/piper
и голоса «Ирина» (RU) и «Михай» (RO) из huggingface.co/rhasspy/piper-voices (лицензии — в карточках моделей). Он выбран по умолчанию;
в «Настройки → Голос» можно выбрать и голоса Windows (например, «Microsoft Irina»). На macOS используются голоса системы (`say`).
